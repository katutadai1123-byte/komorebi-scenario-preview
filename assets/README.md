# 『こもれび館』ミカ過去編・画像素材

WebPをこのディレクトリに置くと、公開プレビューに反映されます。

- `portrait_mika_hospital.webp` — ミカ入院服
- `portrait_mika_gothic.webp` — ミカ私服A
- `portrait_mika_athletic.webp` — ミカ陸上競技服
- `portrait_mika_casual.webp` — ミカ私服B
- `portrait_mika_mother.webp` — **ミカの母親**。第8章の談話スペースの会話で表示
- `BG01_*.webp`〜`BG10_*.webp` — シーン背景10枚（試作素材）

解凍した素材ZIPの `assets/` にあるWebP **15ファイル**を、このリポジトリの `assets/` に一括アップロードしてください。ZIPそのものをアップロードしないでください。

第19章の「母親」は主人公の母であり、ミカの母親の立ち絵を使いません。ファイルが未配置なら従来の代替背景のままでシナリオは再生可能です。
